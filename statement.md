# Statement of Project

## Problem Statement
It is often that we are unable to do our chores on time, marking down our pending tasks. There is a need for a easy-to-understand program that could help us organising our life 

# Scope of Project
The project focuses on creating a console-based TO-DO Task Manager using core Python.  
The scope includes adding, viewing, updating ,deleting and marking the task as complete.  

# Target Users
This program is for people who want a digital version of physical to-do notepad.

# High Level Features
- Nice menu interface
- Lets add a task to the list
- Lets the user see their remaining tasks
- Allows user to update(change) their task
- Delete a task which was added by mistake
- Markdown a task as done on completion
- Exit program
