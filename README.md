# TO-DO LIST TASK MANAGER 
This is a daily task manager. It is console based. It is made using only simple python.

It has five operations, from which you can add tasks you want to do, view tasks, replace a given task, delete task, mark a task as complete.

## FEATURES
Few operations this program does:
◈ add a task to to-do list.
◈ view the entire list.
◈ update a task
◈ markdown a task as completed
◈ delete a given task

## TOOLS USED
Programming languange - Python
Data handling - Lists
Libraries used -  None
Runtime - Python3

## STEPS TO INSTALL & RUN
◈ Download the project folder.
◈ Open terminal or command prompt window in same folder
◈ Run using -
```bash
python main.py
```
